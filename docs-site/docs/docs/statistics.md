**Statistics** summarizes activity recorded for your TavernAI user. Open it from the Statistics button in the main panel and choose **30 days**, **90 days**, or **1 year**.

>![Statistics](/img/docs/statistics_1.png)

## Summary totals

| Total | What it counts |
|---|---|
| **Activity** | Recorded actions, excluding session-lifecycle events such as opening and closing the app. |
| **Messages** | Recorded user-input messages. |
| **Generations** | Completed generations, with error and cancellation counts shown separately. |
| **Tokens** | Recorded input and output tokens from completed generations. |
| **New chats** | Chats created during the period, with the number of Cards created shown below. |
